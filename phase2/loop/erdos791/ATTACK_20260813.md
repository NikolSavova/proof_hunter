# Erdős #791 — first full attack (2026-08-13)

## Honest verdict

No improvement to the asymptotic constant was found in this pass.  The useful
deliverable is a primary-source-audited reduction, a reusable independent
verifier, a bounded search baseline, and an exact CP-SAT model aimed at the
smallest possible same-template win: replace Kohonen's `ell=42,m=510`
certificate by `ell=42,m>=511`.

This pass also found and exactly reproduced a fatal gap in the 2016 Alzahrani
master's thesis's claimed lower-side improvement.  That is relevant prior-art
hygiene, but it does not solve #791.

## Problem and normalizations

Let `g(N)` be the minimum size of a set `A` of nonnegative integers such that
`[0,N]` is contained in `A+A`.  Equivalently, let `n(k)` be the maximum initial
range of a `k`-element additive 2-basis.  The canonical bounds as of this search
are

```text
(2.181025... + o(1)) N <= g(N)^2 <= (3.458823529... + o(1)) N,
```

or, in the reciprocal `n(k)/k^2` normalization,

```text
85/294 <= liminf n(k)/k^2 <= limsup n(k)/k^2 <= 0.4585.
```

The construction-side record is Jukka Kohonen, *An improved lower bound for
finite additive 2-bases*, JNT 174 (2017), 518–524
([arXiv](https://arxiv.org/abs/1606.04770),
[DOI](https://doi.org/10.1016/j.jnt.2016.11.011)).  The analytic upper bound on
`n(k)/k^2` is Gang Yu, *A new upper bound for finite additive h-bases*, JNT 156
(2015), 95–104 ([DOI](https://doi.org/10.1016/j.jnt.2015.04.007)).

## Exact scalable reduction

For `t>=2`, define

```text
V = [0,t]
H = {0,t,2t,...,t^2-t}
S = {0,t+1,2(t+1),...,t^2-1}.
```

For finite nonnegative integer placement sets `I,J,K`, put

```text
A_t = (V+t^2 I) union (H+t^2 J) union (S+t^2 K),
ell = |I|+|J|+|K|.
```

Write `D=J+K`.  A square index `q` is tile-certified precisely when

```text
q in I+J  or  q in I+K  or  (q-1 in D and q in D).                 (C)
```

The last clause is easy to get wrong: one `H+S` parallelogram does not contain
a whole square.  Two consecutive parallelograms at `q-1,q` jointly cover
square `q`.

If every `q=0,...,m-1` satisfies (C), then

```text
[0,m t^2-1] is contained in A_t+A_t,
|A_t| <= ell*t + |I|,
limsup g(N)^2/N <= ell^2/m.
```

The predicate is sufficient, not necessary: same-type sums and tile overhangs
can add finite coverage.  It is nevertheless a clean scalable certificate.

Kohonen's placement is

```text
I = {0,5,112,117,122,127,132,137}
J = {10,16,22,...,106}
K = {0,1,2,3,4,224,225,226,227,228,229,367,368,369,370,371,372}.
```

It has type counts `(8,17,17)`, `ell=42`, and certifies exactly the prefix
`q=0,...,509`.  Thus `m/ell^2=510/42^2=85/294`.  A strict record at the same
size needs only square `510`, i.e. `m=511`, and would give

```text
limsup g(N)^2/N <= 1764/511 = 3.4520547945...,
```

improving `294/85=3.4588235294...`.

## Verification and cheap baseline

`verifier.py` independently checks (C), emits deterministic witnesses, and
also expands the literal integer set `A_t` at `t=2,3,5,10`.  All checks pass.
The certificate and witness SHA-256 digests are recorded in
`VERIFICATION_RESULT.json`; unit tests cover the offset-sensitive
parallelogram rule.

The deterministic search in `search.py` evaluated 332,498 candidates:

- all 22,080 single-coordinate replacements in `[0,540]`;
- 60,418 pairs of moves, each displacement at most 6;
- 250,000 seeded simulated-annealing proposals.

None certified `m>=511`.  No tested one-coordinate move, and no tested
radius-6 pair, even preserved the full length-510 prefix.  A diagnostic
near-miss moves `367` to `373` in `K`: it fills square `510` but makes square
`367` the unique hole.  The search landscape transports the boundary hole
rather than simply filling it.

These are bounded negative results, not nonexistence proofs.

## Exact feasibility attempt

`cp_sat_search.py` encodes every product witness and every coverage disjunction
in (C).  It was first validated by recovering the known seven-segment Mrose
placement with `m=14`.

For fixed type counts `(8,17,17)`, coordinates `[0,510]`, and target `m=511`:

- unrestricted, 180 seconds: `UNKNOWN`, 2,613,105 branches;
- at most two arbitrary coordinate replacements from Kohonen: `INFEASIBLE` in
  24 seconds, 114,484 branches and 5,827 conflicts;
- at most three replacements: `UNKNOWN` after 180 seconds and 4,601,360
  branches.
- with all type splits allowed but still `ell=42`: `UNKNOWN` after 180 seconds
  and 66,231,305 branches.

The radius-two result is an exact CP-SAT solver conclusion for the encoded
finite model, but OR-Tools does not emit a proof certificate here.  Treat it as
strong rerunnable evidence, not a formal UNSAT theorem.

## Prior-art kill-search

No post-2017 improvement to Kohonen's one-dimensional interval construction
was found.  The current [Erdős Problems #791](https://www.erdosproblems.com/791)
entry, Kohonen's [zbMATH record](https://zbmath.org/6676833), and Nathanson's
2026 [survey](https://arxiv.org/abs/2605.26425) remain consistent with Kohonen
and Yu as the terminal published references.

Nearby but non-overlapping hazards:

- finite cyclic-group bases use wrap-around and do not certify an integer
  initial interval;
- restricted postage-stamp tables and spectacular small-`k` ratios are not
  asymptotic families;
- sparse-array papers use the overlapping vocabulary “contiguous sum
  co-array” and “minimum redundancy array”; Rajamäki–Koivunen 2021
  ([arXiv](https://arxiv.org/abs/2010.08977)) restates Kohonen but does not beat
  it;
- Weltge–Zyhalko 2026 ([arXiv](https://arxiv.org/abs/2605.19449)) counts
  additive 2-bases rather than improving the extremal constant.

### Alzahrani thesis audit

The 2016 Kent State thesis
([official PDF](https://etd.ohiolink.edu/acprod/odb_etd/ws/send_file/send?accession=kent1479595346428957&disposition=inline))
claims `sigma<=0.4550452314`, which would improve Yu.  Its Section 6 positivity
argument requires a nonnegative periodic weight with nonnegative cosine
coefficients, then selects

```text
u(t) = 9/4 - 100(t-1/2)^4.
```

But `u(0)=-4`.  Moreover, for the autocorrelation kernel identified by the
thesis's displayed endpoint values,

```text
W(1/2) = integral_0^(1/2) u(t)u(t+1/2) dt = -1009/4032 < 0.
```

The exact replay is `audit_alzahrani_kernel.py`.  This violates the pointwise
nonnegativity used to infer the key sum is nonnegative.  The thesis also states
an incompatible zeroth Fourier coefficient and cites a nonexistent equation
at the final step.  Unless a materially different unstated kernel was intended,
the claimed improvement is not established.  This is an audit finding, not a
formal correction endorsed by the author or a journal.

## Decision tree for a second pass

1. **Best immediate continuation:** strengthen the CP-SAT model and run
   portfolio seeds for `ell=42,m=511`; aim for either a placement or a
   certificate-producing SAT/ILP formulation.  First close radius three.
2. **If fixed counts look sterile:** free the `(8,17,17)` split while keeping
   `ell=42`, then search every `ell>=18` with target
   `floor(85*ell^2/294)+1`.  Kohonen exhausted only `ell<=17`, and only against
   the older `2/7` threshold.
3. **If the three-tile template stalls:** exploit its theoretical ceiling near
   `1/3` by designing a fourth segment type.  This has more upside but is a
   larger research project because new exact tile-sum lemmas are required.
4. **Do not pivot to generic finite postage-stamp search:** without a scalable
   composition theorem it cannot improve the asymptotic record.

No claim here should be publicized as a solution or record improvement.
