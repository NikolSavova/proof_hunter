# Point-footprint carry automaton lane

The main result is an exact family of elementary tile languages whose
current-role graph contains `K_r` for every fixed `r`, with fixed phase
overhead and a rigorous macro-to-literal amplifier.  The optimized `K7`
instance escapes the earlier chromatic obstruction, but its asymptotic
edge-state automaton appears to have only self-loops.  No near-lossless
transition-compatible macro assignment is proved.

See `AUTOMATON_RESULT.md` for the theorem, proof, limitations, and
reproduction commands.
