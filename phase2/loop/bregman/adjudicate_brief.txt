BACKGROUND. Bauschke-Macklem-Wang (arXiv:1003.3127) Fact 3.2: if (a) dom f = X, (b) C subset
U = int dom f closed nonempty with cl C* subset U* (C* := grad f(C)), and (c) C is right
D_f-Chebyshev (argmin_{y in C} D_f(x,y) a SINGLETON for every x in U; RIGHT = second argument
varies), then C* is convex. Their Problem 2 asks which hypotheses are necessary.

WE PROVED (four adversarial passes, no error found): for f Legendre on X = R^n with dom f = X
and C subset X ARBITRARY, if argmin_{y in C} D_f(x,y) is a singleton for every x in X, then C is
nonempty and closed and C* is convex. I.e. hypothesis (b) is redundant.

A PRIOR-ART SWEEP NOW CLAIMS THIS IS ALREADY PUBLISHED, in Luo-Meng-Wen-Yao, "Bregman distances
without coercive condition: suns, Chebyshev sets and Klee sets", Optimization 68(8) (2019),
Theorem 3.12 — on the grounds that Theorem 3.12 imposes no dual-closure hypothesis.

HERE ARE THE ACTUAL STATEMENTS, transcribed from the paper (not paraphrased):

  Definition 3.3(b). C is right Chebyshev (resp. right proximinal) if for each x in U,
  ->Pi^f_C(x) is a singleton (resp. non-empty).

  THEOREM 3.12. Suppose that C is ->D_f-proximinal.
   (1) In the following statements, (i) => (ii).
       (i)  For each x in U and y in C:  y in ->Pi^f_C(x)  <=>  <grad f(y) - grad f(c), y - x> <= 0
            for each c in C.
       (ii) C is a ->D_f-sun.
   (2) If U = X, then (i) <=> (ii), and each of them is equivalent to:
       (iii) For each x in U and y in C, if y in ->Pi^f_C(x), then y in ->Pi^f_C(z_2).
   (3) If grad f(U) = U*, and if f* is Gateaux differentiable and strictly convex on U*, then
       (i) is equivalent to:
       (iv) grad f(C) is convex;
       consequently, if in addition U = X, then each of the above statements is equivalent
       mutually.

  THEOREM 3.13. Suppose that f is totally convex at any point of U, that grad f(U) = U*, and
  that f* is locally uniformly totally convex at any point of U*. If C be a boundedly compact
  ->D_f-Chebyshev set, then C is a ->D_f-sun.
