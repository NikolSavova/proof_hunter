### Latest delta: the adaptive cross-pair `D^2` charge

The six-anchor route below remains valid, but a newer charge is the current
lead.  For a rich fibre `F=(u,s)`, `w=s-u`, define

\[
 X_F(q)=(u+q,w-q,w-(I+J)q)\in D^3.
\]

Every cross pair `(X_F(q)_i,X_F(p)_j)` is a fibre-injective charge into
`D^2`.  The clean fixed route

\[
 \Psi_{02}(F,q,p)=(u+q,w-(I+J)p)
\]

has load `lambda`.  The single estimate

\[
 \boxed{\sum\lambda^2\le K N^{o(1)}\mathcal O_K,
 \qquad K=S/N}                                      \tag{1.1}
\]

implies `O_K<=N^(1+o(1))S` by Cauchy in the `N^2` target.  It handles all
configurations without a common-endpoint split and permits average load
`K`, rather than `N^o(1)`.  The symmetric minimum over all nine cross pairs
is still stronger.

The incidence triple has the exact common factor

\[
 \Phi(X)=(x_0+x_1,x_2+(I+J)x_0)=(s,s+Ju),
\]

which recovers the fibre.  A full nine-projection orthogonal array is
therefore impossible; the missing step is a quantitative sparse

 M\le\mathcal B_{\rm sw}

### Latest support-gate audit: quadratic fibres require cubic compensation

A second exact closing target is now isolated:

\[
 |2A-(I+J)A|\ge |A|^{3-o(1)}.
\]

Because the left side is `O(m^2)` in an `m` by `m` grid, this would also
give `|A|<=m^(2/3+o(1))`.  Costas, closure, and perpendicular-ruler stresses
all have support of constant order `|A|^3`.

The naive pointwise route to this support estimate is decisively false.
For arbitrarily large integral planar distance-Sidon sets `A`, there is a
nonzero `d in D=A-A` with

\[
 |D\cap(D+(I+J)d)|=\Omega(|A|^2).
\]

The construction is an `s`-mark diagonal Golomb ruler plus one horizontal
edge whose length is a popular difference of `R-R`.  Crucially, the same
diagonal arm injects `s^2(s+1)/2=Theta(|A|^3)` triples into
`2A-(I+J)A`.  Thus heavy dilation fibres must be paid for by transverse
support growth; no subquadratic maximum-overlap theorem can work.  This is
the support analogue of the correction from maximum swap degeneracy to the
size-biased orientation-energy gate.  Read
`DILATED_PAIR_SUM_HEAVY_FIBRE_BARRIER.md` and run
`verify_dilated_pair_sum_heavy_fibre_barrier.py`.

### Cubic support is proved in the high-resonance-index affine branch

The alternate support target is now established for the main affine
low-doubling adversaries.  If `A=T A_0`, where `A_0` is vector-Sidon, put

\[
 \Gamma_T=\{z:T^{-1}JTz\in\mathbb Z^2\},\qquad
 H=|((A_0-A_0)\setminus\{0\})\cap\Gamma_T|.
\]

An exact collision calculation proves

\[
 |2A-(I+J)A|\ge
 {|A|^6\over2|A|^3-|A|^2+H(|A|^2+|A|-1)}.
\]

Thus `H<=|A|^(1+o(1))` gives cubic support.  The resonance-index formula
and a lattice-point count give

\[
 H\ll M^2/I_T+M,
 \qquad I_T=[\mathbb Z^2:\Gamma_T],
\]

for `A_0 subset [0,M]^2`.  In particular every determinant-prime affine
Welch--Costas stress has `H=O(|A|)` and satisfies the uniform explicit bound

\[
 |2A-(I+J)A|\ge |A|^3/7.
\]

This closes the generic/high-index affine branch.  The remaining support
problem is localized to low-index, nearly quarter-turn-stable additive
models.  Read `DILATED_PAIR_SUM_RESONANCE_BRANCH.md` and run
`verify_dilated_pair_sum_resonance_branch.py`.

The same note also closes the line-covered inverse branch.  If `A` has `h`
points on one affine line, those points alone give exactly
`h^2(h+1)/2` distinct values in `2A-(I+J)A`.  Hence any cover of `A` by
`|A|^(o(1))` lines already proves cubic support.  The remaining low-index
model must therefore be genuinely two-dimensional as well as sparse.

### Latest exact decomposition: spread or a Gaussian-lattice hard core

The low-index affine branch now has an exact structural decomposition.
For `A=T A_0`, put `R=T^(-1)JT` and

\[
 \Gamma=\{z\in\mathbb Z^2:Rz\in\mathbb Z^2\}.
\]

Partition `A_0` into `Gamma`-cosets with occupancies `k_C`, and let

 H=\sum_C k_C(k_C-1),

 \boxed{|2A-(I+J)A|\ge |A|^3/(2h)}.

 \boxed{|2A-(I+J)A|\ge

There is no overlap loss.  This localizes every remaining affine

### Endpoint switching gives exact self-reproducing neighborhoods

There is now a compact graph form of the density-increment problem.  Put
`U=A+J(A-A)` and, for each `d in D=A-A`, take the block

\[
 B_d=A+Jd\subset U.
\]

The blocks are edge-disjoint copies of `K_k`.  If

\[
 r_x=|\{(a,d):x=a+Jd\}|
\]

and `A_x` is the set of the corresponding first endpoints, then the closed
neighborhood of `x` in the block-shadow graph is exactly

\[
 \boxed{N[x]=x+(A-A_x),\qquad |N[x]|=1+(k-1)r_x.}
\]

Thus a fibre of multiplicity `h` reproduces `h` endpoint stars with exact
local expansion `1+h(k-1)`; the only collisions are at their common centre.
This makes heavy-fibre compensation fully explicit.  The remaining global
theorem is now the assertion that these endpoint-decorated neighborhoods
cannot overlap with projective-plane efficiency.  A general linear block
system can, so the proof must retain the translate, quarter-turn, and
complete-difference decorations.  Read
`ROTATED_TRANSLATE_SELF_REPRODUCTION_GATE.md` and run
`verify_rotated_translate_self_reproduction.py`.

The same note now removes the projective-plane baseline exactly.  For
distinct outputs `x,y`, put `delta=y-x`.  Apart from their unique common
block, every common neighbor is in bijection with a pair
`(p,q) in A_x times A_y` for which

\[
 \delta+p-q=a-b\in(A-A)\setminus\{0\},
\]

with the two noncentral endpoint conditions `a!=p`, `b!=q`.  Consequently

\[
 |N[x]\cap N[y]|=k\,1_{x\sim y}+|\mathcal T_{x,y}|.
\]

The missing density increment is therefore precisely a size-biased
aggregate bound for this shifted six-endpoint count, not a bound for the
unavoidable common `K_k` overlap.

There is an exact warning: the *unweighted* aggregate is self-dual,

\[
 \sum_{\{x,y\}}|\mathcal T_{x,y}|
 =(k-1)^2\sum_z{r_z\choose2}.
\]

Every unordered pair of blocks through `z` permits exactly `(k-1)^2`
noncentral endpoint switches, and these give all transverse wedges.  Thus
ordinary inclusion--exclusion on the expanded neighborhoods simply
reproduces the original collision moment.  The next step must orient the
wedges and control a convex size-biased load, discard a structured part and
charge it to new support, or exploit genuine shrinkage of the Gaussian-core
lattice.  Do not pursue an unweighted neighborhood-overlap sum.

The exact oriented restart is now also written.  Let `H_A` be the graph on
blocks, joining two blocks when they meet, let

\[
 I=|E(H_A)|=\sum_x{r_x\choose2},
\]

and let `S_x` be the pencil of blocks through `x`.  Orient `H_A` and put

\[
 c_x=|\{d\to e:d\in S_x, e\notin S_x\}|.
\]

Propagating one base orientation across its full `(k-1)` by `(k-1)`
endpoint-switch biclique gives the exact load `(k-1)c_x` at `x`.  Therefore

\[
 |A+J(A-A)|\ge{(k-1)^2I^2\over\sum_xc_x^2}.
\]

The full support theorem follows in the collision-dominant branch from the
single pencil-orientation estimate

\[
 \boxed{\sum_xc_x^2\le I^2/k^{1-o(1)}}.
\]

This is the current smallest endpoint-sensitive density-increment gate.  A
random orientation has expected cost `sum_x(b_x^2+b_x)/4`, where `b_x` is
the unoriented pencil boundary, so independent balancing alone is
insufficient; the gain must come from a correlated orientation or a
structural split.

There is now a sharp warning about what that structural split must retain.
The punctured affine-line system in
`AFFINE_DOUBLE_ENDPOINT_ORIENTATION_BARRIER.md` has two orthogonal proper
endpoint colourings, a third proper incidence label, every pencil is a
three-coordinate matching, and every base edge has a unique pencil centre.
Nevertheless every
orientation satisfies

\[
 {k\sum_xc_x^2\over I^2}\gg k.
\]

Thus neither endpoint ordering, nor even the abstract three-coordinate
matching design, can prove the gate.  The translate identity `B_d=A+Jd`, radial
uniqueness, and complete-difference realization must remain coupled.

## 2. What was accomplished in the latest attack

For a distance-Sidon set `A` in an `m` by `m` grid, put

\[
 D=A-A,\qquad N=|D|,\qquad S=|D+D|,
\]

and let `J` be quarter-turn.  The earlier reductions show that the grid
upper bound follows from the adaptive off-diagonal estimate

\[
 \mathcal O_K\le N^{1+o(1)}S.                 \tag{2.1}
\]

The last several hours replaced a loose cross-fibre charge first by an exact
two-anchor graph and then by a swap-coupled six-anchor charge.

For each normal seven-incidence configuration, endpoint realization gives

\[
 \omega=(\epsilon(c),m(u)-m(c)),\qquad
 \ell=w-(I+J)q,\qquad z=w-q.
\]

For fixed `omega`, make a bipartite multigraph `G_omega` with an edge
`(ell,z)` for every configuration.  Orient each edge toward its endpoint of
smaller global degree, with a fixed tie rule.  This charge is injective
inside every rich fibre.  Together with two exact common-endpoint routes it
lands in at most `10NS` labelled keys.

The decisive exact inequality is

\[
 \sum\lambda_N^2\le
 \mathcal B_N:=\sum_\omega\sum_{e=(\ell,z)\in G_\omega}
 \min\{d_L(\ell),d_R(z)\}.                    \tag{2.2}
\]

This is not an estimate: it follows directly from the orientation.  It
removes the one-sided star obstruction which defeated the prior charge.
Any large normal second moment must now contain many edges with both anchor
degrees large in the same endpoint-midpoint graph.

The two fixed-anchor collision systems are also exact.  If two preimages
differ by `(eta,rho,pi)` in their base and two popular shifts, then the
left-anchor displacements are

\[
 \eta,\ \eta+\rho,\ \eta+\pi,\ 0,\ J\rho,
 (I+J)\rho-\pi,\ (I+J)(\rho-\pi),              \tag{2.3}
\]

and the right-anchor displacements are

\[
 \eta,\ \eta+\rho,\ \eta+\pi,\ 0,\ \rho-\pi,
 -J\rho,\ \rho-(I+J)\pi.                      \tag{2.4}
\]

The common endpoint decoration forces `eta`; it is not a free affine
variable.  Both adaptive-popular shifts remain present.

Every ordered configuration `(q,p)` also contains its swapped partner
`(p,q)`.  Retaining both endpoint labels produces four `w`-anchor cells,
and the two moving heads produce two more cells.  Charging to the least
popular of these six candidates gives a new exact envelope

\[
 \sum\lambda_6^2\le\mathcal B_6\le\mathcal B_N.               \tag{2.5}
\]

The complete charge remains fibrewise injective and now lands in at most
`18NS` labelled keys.  The larger constant is irrelevant; the substantial
gain is that a counterexample must be simultaneously dense under the swap
involution, both endpoint labels, four paired anchors, and two heads.

## 5. Other durable progress and barriers

The direct attack has accumulated substantially more than the final gate:

- Complete rectangular, Gaussian-ideal, and arbitrary oblique lattice
  fibres were classified.  The sharp universal height threshold is
  `M >> r^(3/2)`, exactly the exponent needed at the cube-root scale.
- Sparse oblique shear examples show that even near-full density, three
  affine fibre copies, radial uniqueness, and adaptive bidirectional
  popularity do not recover a polynomial complete patch.  Complete
  difference endpoint realization is indispensable.
- The orthogonal-energy problem was localized to a support-adaptive rich
  tail.  High-support Ruzsa branches, collinear branches, algebraic-curve
  branches, generic affine images, and large resonance-index branches were
  separated or closed.
- Opposite-endpoint charges, exact popular-pair rectangles, an eight-form
  fractional-basis collision majorant, and endpoint-switched two-moment
  charges remain valid fallback interfaces.
- The common-endpoint fallback is not arbitrary: a repeated local midpoint
  class forces three affine copies in `A` and squared-distance ratio
  `1:1/4:5/4`.
- Generic hypergraph codegrees, anti-Ramsey proper coloring, raw distance
  energy, DRC, additive BSG, ordinary third energy, two-sided sumset
  products, scalar Bessel positivity, full directional PSD relaxations,
  and density-to-complete-patch extraction were all shown to bottom out at
  the grid or admit explicit countermodels.  Do not restart these lanes
  without a new endpoint-sensitive ingredient.
- The positive-definite audit is now exponent-sharp as a barrier: exact
  mixed quarter-turn moments, universal radial kernels, support-packing
  duals, and scalar Bessel shell inequalities all admit genuine examples
  or pseudoconfigurations too large for a cube-root proof.  Any successful
  spectral argument must use nonlinear endpoint compatibility, not only
  positivity or the occupied-radius set.
- The prime-power upper framework has a local entropy barrier and will not
  reach exponent `1/3`; its value is the separate explicit partial result
  `0.494586`.

## 6. Best next move

Work on an endpoint-sensitive density increment inside the Gaussian core,
while retaining the `K`-scaled cross-pair estimate (1.1) as the aggregate
closing gate.

1. Use the exact resonance-coset decomposition to prune to a large
   quarter-turn-stable lattice core.  Track its index, scale, and ambient
   endpoint contribution; a recursion on core size alone is too weak.
2. On the surviving core, use the exact neighborhoods
   `N[x]=x+(A-A_x)`.  Prove a size-biased overlap bound after removing the
   unique common-block contribution.  The unweighted overlap total is
   exactly self-dual and gives no gain, so an orientation or convex pruning
   is mandatory; this is the graph version of the endpoint density
   increment.
3. Prefer the pencil-cut formulation: orient the block-intersection graph
   so that `sum_x c_x^2<=I^2/k^(1-o(1))`, but retain the full translate and
   complete-difference geometry.  The affine endpoint barrier proves that
   even two endpoint colourings plus a third proper incidence label miss by
   a full factor `k`; a random orientation likewise reaches only the
   fractional boundary cost.
4. Write every record as two incidence triples `X,Y in D^3` with
   `Phi(X)=Phi(Y)`.  Dyadically prune on the nine cross-coordinate
   codegrees at the natural threshold `tK`.
5. Use the covariance identity for the two components of `Phi` to force a
   nonquasirandom cross projection in every nonconstant-fibre core.
6. Turn that correlation into a density increment while retaining all nine
   cross projections.  Dense regularity is insufficient; the loss must be
   polynomially controlled at the sparse `K` scale.
7. The radial transversals show that the affine/common-factor system alone
   is false.  The increment must use the endpoint identity
   `widehat(1_D)=|widehat(1_A)|^2-(|A|-1)` or an equivalent combinatorial
   endpoint-switch statement.
8. The fixed-route collision displacements are
   `delta,0,delta+pi,delta+(I+J)pi,Jpi,(I+J)(delta+pi),0`.
   Any inverse theorem must retain all five nonzero translated copies.
9. If the fixed route develops a genuine counterexample, use the symmetric
   minimum over all nine `D^2` charges, then combine it with the six
   endpoint-anchor candidates by normalized minimum degree.

The practical progress estimate is: the construction/verification
architecture is mature, and the full conjecture is reduced to one crisp
new combinatorial inequality, but that inequality is of genuinely
open-problem strength.  We are meaningfully closer to a proof route, not
close enough to predict completion.
