# Branching profile queries grow only at fresh construction charts

**Date:** 2026-08-15.  All logarithms are base two.

## Verdict

The stationary `q`-calibration condition in
`CONTINUUM_PROFILE_COHERENCE_GATE.md` is not supplied by the live recursive
wrapper.  A `q`-role parent uses `q` independent physical child copies.
For one construction chart and one retained reset chart, copy `i` is asked
for only one ordered pair of child directions.  Ordered-pair transitivity
is exact, and the prescribed pair can be retained while making an exact
linear strong seam.  Thus the `q` sibling levels do not become `q`
calibration queries in one copy.

There is an exact query-set ledger, but it does **not** force pathwise
growth either.  If `S_v` is the set of charts exported by a node and
`gamma_v` is the chart used to construct it, a child is queried in the
pullback of `S_v union {gamma_v}`.  Consequently a root path with `r`
initial marks and `nu` genuinely fresh construction charts uses at most

\[
                              r+\nu.                        \tag{1}
\]

directions in a primitive descendant.  A branching grammar may take its
first exported mark to be its construction/current-assembly chart at every
level.  With one second reset mark this gives `r=2` and `nu=0`: the state
remains `Pi_2` at arbitrary depth.  Historical construction charts are
existential witnesses for the direction-invariant number `W` and need not
be exported separately.

If a proposed construction does introduce a fresh chart at every level,
then the worst-case width is path depth.  For the balanced quarter wrapper,
where the number of roles at scale `N` is `Theta(log N)`, that depth is

\[
                    h=\Theta\left({\log N\over\log\log N}\right),       \tag{2}
\]

not `Theta(log N)`.  This is an optional fallback, not a constraint on the
live recycled-mark recursion.  In either case, no one copy receives the
`q` prescribed sibling ramp levels.

The known polynomial coherent-itinerary bound also shows that this weaker
state does not pay at coefficient scale by state counting alone.  Fixing
all projective chamber itineraries along one balanced path costs at most

\[
              O\left({(\log N)^2\over\log\log N}\right)
                         =o((\log N)^2)                    \tag{3}
\]

bits.  The recycled two-mark grammar pays even less.  Hence neither
ordered-pair transitivity nor cross-ratio bookkeeping closes the branching
recursion.  A positive theorem still needs an ordinary-face potential
attached to the **decorated two-mark seam state**, not merely a bound on how
many profile words occur.

There is one exact positive branch.  If a parent realization is a separated
cyclic shell with the one-gap profile property, menu branching is irrelevant:

\[
 V(P)\ge A^{q-3}\left(\prod_{i=1}^q H_i\right)^{1/q}.       \tag{4}
\]

For `A=2^L`, `q=(1/4+o(1))L`, and
`log H_i\ge(1/4-o(1))L^2`, equation (4) is
`log V(P)\ge(1/2-o(1))L^2`.  Therefore the only live branching menu is one
whose chosen reset realizations systematically destroy the separated
one-gap splice.  This is a geometric seam condition; it is not a
multi-calibration condition on one child.

This report retracts no part of the stationary conditional theorem itself.
It proves that its hypothesis is not generated by ordinary branching and
identifies the exact two-mark state which can be recursively closed.

## 1. Exact query-set recursion

Consider a rooted recursive composition tree.  At an internal node `v`,
let `gamma_v` be the construction direction in which its exact local
first-cap/last-cup or strong-glue recurrence is evaluated.  Let `S_v` be a
set of exported directions in which profiles of the completed set at
`v` must be retained for its ancestors.  If child `w` is inserted by an
affine map `T_(v,w)`, the exact profile data requested from `w` are

\[
 S_w=T_{v,w}^{*}\bigl(S_v\cup\{\gamma_v\}\bigr).           \tag{5}
\]

Repeated directions may be merged, so

\[
                         |S_w|\le |S_v|+1.                  \tag{6}
\]

Equation (5) is just functoriality of a projection functional under an
affine embedding.  The construction recurrence needs the child cap/cup
profile in the pullback of `gamma_v`; every retained parent profile in
`S_v` needs the child profile in its corresponding pullback.  There are no
other direction queries.

Let `nu` be the number of levels on a root path at which `gamma_v` is not
already in `S_v`.  Starting with `|S_root|=r` and iterating (6) proves (1).
Notice that the number of siblings never appears.  A parent may use profile levels
`0,1,...,q` across `q` different copies, but every one of those copies adds
at most the one direction `gamma_v` to its inherited query set.

In particular, take `S_v={gamma_v,beta_v}`, where `beta_v` is the one
future reset chart.  Choose the first mark of every child to be the
pullback of `gamma_v` and its second mark to be the pullback of `beta_v`.
Then `gamma_v in S_v`, and the same two-mark convention repeats at the
next level.  No historical chart has to be retained: `W(P_v)` is an
intrinsic count after the type has been constructed.  This is the exact
recycled-mark recursion which invalidates the proposed `Pi_h` obstruction.

If instead an application exports directions which exclude `gamma_v`, the
query set can grow by one.  Iterating this choice gives the optional
pathwise itinerary in Sections 3--4.  It is not forced by the wrapper.

## 2. Ordered pairs can be synchronized without breaking a strong seam

The following lemma removes a possible loophole in the branching
correction.

> **Lemma 1 (two-mark strong insertion).**  Let `Q_1,...,Q_t` be rational
> planar general-position configurations.  In `Q_i`, choose two distinct
> rational generic projection functionals `xi_i,eta_i`.  Choose two
> distinct rational ambient functionals `alpha,beta`.  There are
> orientation-preserving rational affine images of the `Q_i` such that
> `alpha,beta` pull back projectively to `xi_i,eta_i`, respectively, and
> the images form an exact ordered strong composition in the `alpha` order.
> The affine images may independently reflect orientation; if the two
> ordered direction pairs have the same cyclic orientation, the image can
> be chosen orientation-preserving.

After one global rational change of coordinates, take
`alpha(x,y)=x` and `beta(x,y)=y`.  Because `xi_i,eta_i` are independent,
the rational linear map

\[
                    p\longmapsto(a_i\xi_i(p),b_i\eta_i(p))             \tag{7}
\]

is nonsingular.  Positive rational `a_i,b_i` give the two oriented
pullbacks exactly; the determinant records whether the image reflects.
If only projective direction lines are marked, either sign may instead be
chosen.  Equation (7) gives the two required pullbacks.

It remains to place consecutive blocks.  In the `x` order, every directed
within-block chord `d=(d_x,d_y)` has `d_x>0`.  If the next block is
translated from the preceding one by

\[
                              v=(R,-M),                    \tag{8}
\]

then, uniformly over the finitely many within-block chords,

\[
                         \det(d,v)<0,\qquad \det(v,d)>0     \tag{9}
\]

once `M` is sufficiently large; then choose `R` large enough to separate
the `x` intervals and enlarge `M` again if necessary.  Small positive
rational rescaling of each block makes the same strict inequalities hold
for every actual cross-block triple.  Iterating with successively larger
rational separations gives the exact strong composition.  Translations
and positive scalar rescalings do not change either marked direction or
any internal order type.  This proves the lemma.

Lemma 1 proves more than abstract `PGL_2` pair transitivity: in the linear
strong-glue model the open seam inequalities can be met at the same time.
It does **not** determine the completed parent's reset spectrum.  That
spectrum also depends on cross-child pair directions and the insertion
gauge, exactly as recorded in
`PARETO_TWO_LEVEL_RECURSIVE_MENU.md`.

## 3. Even the all-fresh fallback has sublinear profile depth

Let `N_k` be the point count after `k` balanced wrapper levels and put
`L_k=log N_k`.  If the number of roles satisfies

\[
                   cL_k\le q_k\le CL_k                  \tag{10}
\]

for fixed positive constants and every sufficiently large `k`, while
anchors contribute only `O(q_k)`, then

\[
                   L_{k+1}=L_k+\log L_k+O(1).           \tag{11}
\]

Summing the reciprocal increments, or grouping the `L_k` into dyadic
intervals, gives

\[
 h=\Theta\left(\int_2^{L_h}{dx\over\log x}\right)
   =\Theta\left({L_h\over\log L_h}\right),              \tag{12}
\]

which proves (2) for the all-fresh fallback.  The same dyadic summation gives

\[
                   \sum_{k<h}L_k
                    =O\left({L_h^2\over\log L_h}\right). \tag{13}
\]

Thus even if every construction chart is fresh, a localization charge
linear in the logarithm of the current point count at every level is
subquadratic along a root path.  In the recycled-mark grammar `nu=0`, so
this fallback estimate is unnecessary.

## 4. Coherent itinerary entropy is too small

For an `M`-point completed child there are at most
`m=binom(M,2)` critical projection directions.  For `s` fixed ambient
queries, the chamber itinerary induced by one projective reparameterization
has at most

\[
                              O((sm)^3)                   \tag{14}
\]

possibilities: the walls `g(w)=d_j` are `sm` projective hyperplanes in the
three-dimensional parameter space `PGL_2`, with the determinant-zero
quadric removed.  This is the exact polynomial itinerary theorem in
`BAD_PAIR_RANK4_PIQ_CLASSIFICATION.md`.

At a fresh-chart level `k`, fixing such an itinerary therefore costs

\[
                       O(\log s+\log M)=O(L_k+\log h)     \tag{15}
\]

bits.  Sum (15) over an all-fresh path and apply (12)--(13) to obtain (3).  This is
an entropy audit, not a construction: polynomially many itineraries can
still differ in ordinary-face content.  It proves only that a
cross-ratio/cell-count pigeonhole cannot itself create a quadratic gain.

The activity countermodel in
`PROJECTIVE_RAMP_ACTIVITY_COUNTERMODEL.md` already survives the stronger
stationary `Theta(L)`-query pattern with mean formal rank `Theta(L)`.
Consequently endpoint variation and activity alone cannot exploit the
smaller path width in (2); genuine downward-closed planar circuit coupling
would still be needed.

## 5. The separated branching branch is already closed

Suppose one actual parent has `q` lexicographically separated cyclic child
clusters, each with `A` labels and nonempty ordinary-face reservoir `H_i`.
The two directional boundary families of child `i` have sizes `L_i,R_i`
with

\[
                              L_iR_i\ge H_i.              \tag{16}
\]

Omitting macro role `j` exposes a right profile at `j-1`, a left profile at
`j+1`, and one arbitrary singleton in every other retained role.  The
resulting ordinary bank has size

\[
                         B_j=R_{j-1}L_{j+1}A^{q-3}.       \tag{17}
\]

Multiplication over all gaps and (16) prove (4).  The output occupancy mask
recovers the gap, so there is no summation over alternative parent types and
no branching-menu load.  This is the exact theorem in
`CENTRAL_SHELL_PROFILE_RECURRENCE.md`.

Accordingly a sub-half branching construction must avoid this geometric
hypothesis at every live parent type.  The precise unresolved object is a
decorated recursive type whose chosen construction seams are cheap, whose
future profile is cheap, and whose nonseparated seam failures prevent every
one-gap bank.  Neither scalar `Pi_2` data nor a stationary `Pi_q` profile
word is the correct substitute.

## Scope

This is a correction and a gate, not an EIC' closure and not a sub-half
construction.  It establishes:

1. no natural `q`-direction same-copy hypothesis is supplied by sibling
   branching;
2. the exact inherited coherence width is `r+nu`, and a recycled `Pi_2`
   grammar has `nu=0`;
3. even the optional all-fresh state-counting cost is subquadratic; and
4. separated cyclic realizations nevertheless pay coefficient one half.

The remaining nonseparated decorated-two-mark seam recursion is genuinely
open.
