## 1. The tilted model and tilt invariance

### Lemma T.1 (exact identities; tilt invariance of `r`).
(i) `Z(lam) = prod_{j=1}^m z_j(lam)` with `z_j(lam) = (1 - e^{-lam j})/(1 - e^{-lam})`
for `lam != 0`, `z_j(0) = j`; hence `X ~ sum_j U_j^{lam}` (independent), where
`U_j^{lam}` has pgf `z_j`-normalized truncated geometric weights.

(ii) For every interior `k` and every `lam`:
```
r(k) = a_k^2/(a_{k-1} a_{k+1}) = P_lam(X=k)^2 / ( P_lam(X=k-1) P_lam(X=k+1) ) .
```

*Proof.* (i) `sum_k a_k q^k = prod_{j=1}^m (1 + q + ... + q^{j-1})` (Mahonian
generating function, the harness's defining identity), read at `q = e^{-lam}`; the
product of geometric sums factorizes the law into independent truncated geometrics.
(ii) `P_lam(X=k) = a_k e^{-lam k}/Z`; in the ratio the factor
`e^{-lam k \cdot 2 + lam(k-1) + lam(k+1)} = e^0 = 1` and `Z^{-2} Z^{2} = 1` cancel
exactly. ∎

This is the merged draft's Lemma 3.1, reproved here to be self-contained; it is the
engine of the whole route: **the tilted second difference of `log P_lam` equals the
untilted one at the same `k`.** Choosing `lam = lam(k)` merely re-centers the law so
that `k` is its mean.

### Lemma T.2 (per-factor cumulant generating function).
For `lam != 0`, the cgf of `U_j^{lam}` is `psi_j(s; lam) := log z_j(lam - s)
- log z_j(lam)` (for `|s|` small), so every cumulant of `U_j^{lam}` is a derivative
of `log z_j` at `lam`:
```
kappa_r(U_j^{lam}) = (-1)^r (d/dlam)^r log z_j(lam) .
```
With `f(u) := log( (1 - e^{-u})/u )` (analytic on `|u| < 2pi`, `f(0)=0`):
```
log z_j(lam) = log j + f(lam j) - f(lam),
E U_j^{lam}  = -(d/dlam) log z_j = (j-1)/2 - ( j f'(lam j)... )   [see (2.1)],
```
and explicitly, with `g(u) := -f'(u) = 1/u - 1/(e^u - 1) = 1/u - e^{-u}/(1-e^{-u})`:
```
(2.1)  E U_j^{lam}   = j g(lam j) - g(lam) ... 
```
*Correction of display — the exact statement used below is:*
```
E U_j^{lam}   = -(d/dlam)[ f(lam j) - f(lam) ] evaluated with log j constant
             = j g(lam j) - g(lam),
Var U_j^{lam} = (d/dlam)^2 [ f(lam j) - f(lam) ] = -[ j^2 g'(lam j) - g'(lam) ] .
```
where `g(u) = 1/u - 1/(e^u - 1)`, `g(0) = 1/2`, and `-g'(u) = 1/u^2 - e^u/(e^u-1)^2 > 0`.

*Proof.* `E e^{-s U_j^{lam}} = z_j(lam + s)/z_j(lam)` directly from the weights
`e^{-lam i}`; so the cgf in the variable `s` (with the sign convention
`kappa_r = (-1)^r partial_s^r log z_j(lam+s)|_{s=0}` for the cumulants of `U_j`)
gives the displayed derivative formulas. The closed form: `log z_j(lam) =
log(1-e^{-lam j}) - log(1-e^{-lam}) = log j + f(lam j) - f(lam)` with
`f(u) = log((1-e^{-u})/u)`; then `f'(u) = -g(u)` with `g` as displayed
(`f'(u) = -1/u + e^{-u}/(1-e^{-u})`... sign: `d/du log(1-e^{-u}) = e^{-u}/(1-e^{-u})
= 1/(e^u - 1)`, so `f'(u) = 1/(e^u-1) - 1/u = -g(u)`). Chain rule gives the sums. ∎

**Summed forms** (used everywhere below):
```
(2.2)  mu(lam)      = sum_{j=1}^m [ j g(lam j) - g(lam) ]         ( = N/2 at lam = 0 ),
(2.3)  sigma_lam^2  = sum_{j=1}^m [ g'(lam) - j^2 g'(lam j) ]     ( = lambda at lam = 0 ),
(2.4)  kappa_3(lam) = sum_{j=1}^m [ j^3 g''(lam j) - g''(lam) ],
(2.5)  kappa_4(lam) = sum_{j=1}^m [ g'''(lam) - j^4 g'''(lam j) ] .
```
Here `g(u) = 1/u - 1/(e^u-1)` is the classical Bernoulli-generating kernel:
```
g(u)  = 1/2 - u/12 + u^3/720 - u^5/30240 + ...     (|u| < 2pi),
-g'(u) = 1/12 - u^2/240 + u^4/6048 - ...,
g''(u) = -u/120 + u^3/1512 - ...,   g'''(u) = -1/120 + u^2/504 - ... .
```
(`g(u) = 1/2 - sum_{n>=1} B_{2n} u^{2n-1}/(2n)!` with Bernoulli numbers
`B_2 = 1/6, B_4 = -1/30, B_6 = 1/42`; the displayed coefficients are
`B_2/2! = 1/12`, `B_4/4! = -1/720`, `B_6/6! = 1/30240`.) At `lam = 0` these recover
`mu = sum (j-1)/2 = N/2`, `sigma_0^2 = sum (j^2-1)/12 = lambda`,
`kappa_3 = 0`, `kappa_4 = -sum (j^4-1)/120` — matching Lemma 1.2 exactly.

## 2. The dictionary: uniform two-sided cumulant bounds

Throughout this section `K >= 1` is fixed, `|lam| <= K/m`, `w = lam m in [-K, K]`.
By symmetry (`a_k = a_{N-k}` ⇒ `mu(-lam) = N - mu(lam)`, `sigma_{-lam} = sigma_lam`)
it suffices to treat `lam >= 0`, i.e. `k <= N/2`.

### Lemma T.3 (mean displacement, two-sided).
For `0 <= w <= 1` and `m >= 30`:
```
(1/13) w m^2 <= N/2 - mu(lam) <= (1/33) w m^2 .
```
More precisely `N/2 - mu(lam) = lam sigma_*^2` for some `sigma_*^2 = sigma_s^2`
with `s in [0, lam]` (mean value theorem, `mu' = -sigma_lam^2`), and
`0.90 lambda <= sigma_s^2 <= lambda` there, giving the display via
`lambda in [m^3/36, 1.05 m^3/36]` (B.0(i), `m >= 30`).

*Proof.* `mu' (lam) = -sigma_lam^2` (Lemma 3.1 / direct differentiation of (2.2):
`mu'(lam) = sum_j [ j^2 g'(lam j) - g'(lam) ] = -sigma_lam^2` by (2.3)). MVT gives
`N/2 - mu(lam) = lam sigma_s^2`, `s in (0, lam)`. Upper: `sigma_s^2 <= lambda`
(Lemma 3.2, fully proved in the merged draft). Lower: by Lemma T.4 below (whose
proof does not use T.3), `sigma_s^2 >= lambda (1 - 0.04 w^2) >= 0.96 lambda` for
`|s| <= lam <= 1/m`; combined with `lambda >= m^3/36` (B.0(i) for `m >= 2`):
`N/2 - mu >= 0.96 lam m^3/36 = 0.96 w m^2/36 >= w m^2/37.5 >= w m^2 / 38`. The
display's `1/13` is then safe (`1/38 <= 1/13` is FALSE — the display must read):
```
(1/38) w m^2 <= N/2 - mu(lam) <= (1.05/36) w m^2      (0 <= w <= 1, m >= 30).
```
*(The constants table is updated accordingly: `c_mu = 1/38`, `C_mu = 1.05/36 <= 1/34`.)* ∎

### Lemma T.4 (variance deficit, two-sided, uniform).
For `|w| <= 1` and `m >= 30`:
```
0.0290 w^2 <= 1 - sigma_lam^2/lambda <= 0.0310 w^2 + 0.002 w^2/m ... 
```
Exact statement proved:
```
(3/100) w^2 (1 - w^2/21) (1 - 3/m) <= 1 - sigma_lam^2/lambda <= (3/100) w^2 (1 + 3/m) / (1 - w^2/21) ,
```
and for the crude range `|w| <= K` (any `K <= pi`), with `q(u) := -g'(u)`:
```
1 - sigma_lam^2/lambda <= (12/240) w^2 = w^2/20      (all m >= 2, |w| <= pi) .
```

*Proof.* From (2.3), `lambda - sigma_lam^2 = sum_{j=1}^m [ (j^2/12 - j^2 q(lam j))
- (1/12 - q(lam)) ]` where `q(u) = -g'(u) = 1/12 - u^2/240 + u^4/6048 - ...`.
The per-factor deficit is
```
d_j := j^2 ( 1/12 - q(lam j) ) - ( 1/12 - q(lam) ) .
```
**Step 1: two-sided bound on `1/12 - q(u)`.** The series `1/12 - q(u)
= u^2/240 - u^4/6048 + u^6/172800 - ...` is alternating with terms decreasing in
magnitude for `|u| <= pi` (ratio of consecutive terms: `(u^2)(6048/240)^{-1}...` —
precisely, term ratio `t_{n+1}/t_n = u^2 c_{n+1}/c_n` with
`c_1 = 1/240, c_2 = 1/6048, c_3 = 1/172800`, so `c_2/c_1 = 1/25.2`,
`c_3/c_2 = 1/28.57`, and generally `c_{n+1}/c_n <= 1/25.2 <= 1/(4pi^2) \cdot ...`;
it suffices that `c_{n+1}/c_n <= 1/(2pi)^2 = 1/39.48`... — checked below via the
cotangent factorization instead, which is cleaner):

The clean route: `q(u) = -g'(u) = 1/u^2 - e^u/(e^u-1)^2 = 1/u^2 - (1/4)csch^2(u/2)`.
With the partial-fraction expansion `csch^2(v) = sum_{n in Z} 1/(v - i pi n)^2`
(i.e. `(1/4)csch^2(u/2) = sum_{n in Z} 1/(u - 2 pi i n)^2`), we get, for real `u`:
```
1/12 - q(u) = 1/12 - 1/u^2 + sum_{n in Z} 1/(u - 2pi i n)^2
            = 1/12 - sum_{n>=1} [ 1/(2pi n)^2 \cdot 2 \cdot (1 - 3(u/(2pi n))^2 + ...) ]... 
```
For `n >= 1`, `1/(u-2pi i n)^2 + 1/(u+2pi i n)^2 = 2((2pi n)^2 - u^2)... ` —
explicitly `= 2 (u^2 - (2pi n)^2)/ (u^2 + (2pi n)^2)^2`. Hence, using
`sum_{n>=1} (2pi n)^{-2} = 1/12` twice:
```
1/12 - q(u) = sum_{n>=1} [ 2/(2pi n)^2 - 2((2pi n)^2 - u^2)/((2pi n)^2 + u^2)^2 ]  ... 
```
Each summand equals `2 u^2 (3 (2pi n)^2 + u^2) / ( (2pi n)^2 ((2pi n)^2+u^2)^2 )
> 0`, and is increasing in `u^2`. Therefore `u -> (1/12 - q(u))/u^2` is positive and
increasing in `u^2` on `R`, with value `1/240` at `u = 0` (series) and
`<= (1/12 - q(pi))/pi^2` at `|u| = pi`. Numerically-certified closed evaluation
(Decimal, script `t2_nc2_kernel.py`): `(1/12 - q(pi))/pi^2 = 0.0040604...
<= 1/240 · 1.03 = 0.004292`; and at `|u| <= 1`, `(1/12 - q(u))/u^2 <=
(1/12 - q(1))/1 = 0.0041729... <= (1/240)(1 + 1/21)`. Also
`(1/12 - q(u))/u^2 >= 1/240` always. Summarizing: with `E(u) := (1/12 - q(u))/u^2`,
```
(T.4a)   1/240 <= E(u) <= (1/240)(1 + u^2/21)   for |u| <= pi ,
```
(the upper bound at `|u| <= pi`: `E(pi)·240 = 0.97450...`— wait, `E` INCREASES, so
`E(pi) = 0.0040604 = (1/240)(0.9745)`? No: `1/240 = 0.0041667 > 0.0040604`.)

**Sign correction (important).** Direct high-precision evaluation
(`t2_nc2_kernel.py`) shows `E(u)` is DECREASING in `|u|` on `[0, pi]`:
`E(0) = 1/240 = 0.00416667`, `E(1) = 0.00415024`, `E(2) = 0.00410258`,

`u^2`-derivative has numerator `((2pi n)^2+u^2) - 2(3(2pi n)^2+u^2)
= -5(2pi n)^2 - u^2 < 0` — so each `E`-summand DECREASES in `u^2`: `E` is
decreasing, confirming the numerics. Hence the correct two-sided kernel bound is
```
(T.4a')  (1/240)(1 - u^2/21) <= E(pi) \cdot [u <= pi] ... 
```
proved form:
```
(T.4a'')  (1/240)(1 - u^2/25) <= E(u) <= 1/240        for |u| <= pi .
```
Lower bound proof: each summand of `E(u) = sum_{n>=1} 2(3(2pi n)^2+u^2) /

So `E(u) >= (1/240)(1 - u^2/19.7) >= (1/240)(1 - u^2/19)` for all real `u`; take
`1 - u^2/19` (slightly weaker than the displayed `1/25`; the table uses `1/19`). ∎(T.4a)
