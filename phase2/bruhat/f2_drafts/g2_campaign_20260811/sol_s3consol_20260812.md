## Lemma SOL.1 — cumulant reduction and positivity of \(F_2\)

For the positively tilted Mahonian law,
\[
\lambda^n\kappa_n=D_n,\qquad n=2,3,4.
\]
Consequently
\[
r_{31}:=\frac{|\kappa_3|\lambda}{s_2}
       =\frac{|F_3|}{F_2},
\qquad
r_{42}:=\frac{\kappa_4\lambda^2}{s_2}
       =\frac{F_4}{F_2},
\]
and
\[
J=r_{31}^2-\frac{r_{42}}2
 =\frac{F_3^2}{F_2^2}-\frac{F_4}{2F_2}.
\]

Moreover,
\[
F_2>0\qquad\text{for every }m\ge2,\ \lambda>0.
\]

### Proof

For the \(j\)-th Mahonian factor,
\[
Z_j(\lambda)=\frac{1-e^{-j\lambda}}{1-e^{-\lambda}}.
\]
Differentiating
\[
\log Z_j(\lambda-t)-\log Z_j(\lambda)
\]
at \(t=0\) gives, for \(n\ge2\),
\[
\kappa_n(X_j)
 =\operatorname{Li}_{1-n}(e^{-\lambda})
  -j^n\operatorname{Li}_{1-n}(e^{-j\lambda}).
\]
Multiplication by \(\lambda^n\) and summation over \(j\) yields
\[
\lambda^n\kappa_n
 =m h_n(\lambda)-\sum_{j=1}^m h_n(j\lambda)
 =D_n.
\]
The ratio identities follow immediately.

For positivity, write \(x=2y\). Then
\[
h_2(x)=\left(\frac{y}{\sinh y}\right)^2.
\]
Since
\[
\frac{d}{dy}\log h_2(2y)
 =2\left(\frac1y-\coth y\right)<0,
\]
\(h_2\) is strictly decreasing. Therefore, for \(m\ge2\),
\[
D_2=\sum_{j=1}^m\bigl(h_2(\lambda)-h_2(j\lambda)\bigr)>0,
\]
because the \(j=1\) term is zero and every \(j\ge2\) term is positive. Hence
\(F_2=\lambda D_2>0\).

The restriction \(m\ge2\) is necessary: for \(m=1\), \(D_2=0\). ∎

## Lemma SOL.2 — strict decrease of \(h_3\) and the sign of \(F_3\)

For every \(y>0\),
\[
3\left(\coth y-\frac1y\right)-\tanh y>0.
\]
Consequently \(h_3\) is strictly decreasing on \((0,\infty)\), and for
\(m\ge2\),
\[
0<F_3< w h_3(\lambda)\le2w.
\]

### Proof

Define
\[
P(t):=t\cosh t+2t-3\sinh t.
\]
Then
\[
P(0)=P'(0)=P''(0)=0,\qquad P'''(t)=t\sinh t.
\]
Thus
\[
P(t)=\frac12\int_0^t(t-u)^2u\sinh u\,du>0
\qquad(t>0).
\]
A direct simplification gives
\[
3\left(\coth y-\frac1y\right)-\tanh y
 =\frac{P(2y)}{y\sinh(2y)}>0.
\]

Also,
\[
h_3(2y)=2y^3\frac{\cosh y}{\sinh^3y},
\]
so
\[
\frac{d}{dy}\log h_3(2y)
 =\frac3y+\tanh y-3\coth y<0.
\]
Hence \(h_3\) is strictly decreasing. Therefore
\[
D_3
 =\sum_{j=1}^m\bigl(h_3(\lambda)-h_3(j\lambda)\bigr)>0
\]
for \(m\ge2\), while positivity of the summands in the original definition gives
\[
D_3<m h_3(\lambda).
\]
Finally \(h_3(\lambda)\le h_3(0)=2\), giving
\[
0<F_3=\lambda D_3<w h_3(\lambda)\le2w.
\]
This supplies the load-bearing sign needed before squaring \(F_3\). ∎

\[

\end{aligned}
\tag{3.1}

\[

\tag{3.2}

\[

\[

\qquad

\tag{3.3}

\qquad

### Proof

The eighth Bernoulli polynomial is
\[
B_8(u)
 =u^8-4u^7+\frac{14}{3}u^6-\frac73u^4
  +\frac23u^2-\frac1{30}.
\]
Its derivative is \(8B_7(u)\), where
\[
B_7(u)
 =u\left(u-\frac12\right)(u-1)
  \left(u^4-2u^3+u+\frac13\right).
\]
The final factor is positive on \([0,1]\), since
\[
u^4-2u^3+u+\frac13
 =u(1-u)(1+u-u^2)+\frac13>0.
\]
Thus \(B_8\) increases on \([0,1/2]\) and decreases on \([1/2,1]\). Since
\[
B_8(0)=-\frac1{30}=-\frac{128}{3840},
\qquad
B_8\!\left(\frac12\right)=\frac{127}{3840},
\]
we get
\[
\sup_{0\le u\le1}|B_8(u)-B_8|
 =\frac{255}{3840}
 =\frac{17}{256}.
\]
Substitution into (3.2) gives
\[
K_{\rm EM}
 =\frac{17/256}{8!}
 =\frac{17}{10321920}.
\]

Identity (3.1) follows from the right-sum Euler–Maclaurin formula through
the \(B_6\) endpoint term, followed by one further integration by parts
without retaining a \(B_8\) endpoint term.

## Lemma SOL.8 — W7 sampled-sum bounds

    return iv.mpf([min(x.a, y.a), max(x.b, y.b)])

class C:
    __slots__ = ("re", "im")

    def __init__(self, re, im=0):
        self.re, self.im = iv.mpf(re), iv.mpf(im)

    def __add__(s, o):
        return C(s.re + o.re, s.im + o.im)

    def __sub__(s, o):
        return C(s.re - o.re, s.im - o.im)

    def __mul__(s, o):
        return C(s.re * o.re - s.im * o.im,
                 s.re * o.im + s.im * o.re)

    def __truediv__(s, o):
        d = o.re * o.re + o.im * o.im
        return C((s.re * o.re + s.im * o.im) / d,
                 (s.im * o.re - s.re * o.im) / d)

    def abs2(s):
        return s.re * s.re + s.im * s.im

def csinh(w):
    eu, emu = iv.exp(w.re), iv.exp(-w.re)
    return C((eu - emu) / 2 * iv.cos(w.im),
             (eu + emu) / 2 * iv.sin(w.im))

def ccosh(w):
    eu, emu = iv.exp(w.re), iv.exp(-w.re)
    return C((eu + emu) / 2 * iv.cos(w.im),
             (eu - emu) / 2 * iv.sin(w.im))

def h_complex(n, z):
    half = C(z.re / 2, z.im / 2)
    sh = csinh(half)
    if n == 2:
        return (z * z) / (C(4) * sh * sh)
    if n == 3:
        return ((z * z * z) * ccosh(half)
                / (C(4) * sh * sh * sh))
    num = ((z * z * z * z)
           * (C(2) * ccosh(z) + C(4)))
    return num / (C(16) * sh * sh * sh * sh)

def M_on_circle(n, R, N, log):
    two_pi = 2 * iv.pi
    worst = iv.mpf(0)
    worst_at = None
    for i in range(N):
        th = hull(two_pi * iv.mpf(i) / iv.mpf(N),
                  two_pi * iv.mpf(i + 1) / iv.mpf(N))
        z = C(iv.mpf(R) * iv.cos(th),
              iv.mpf(R) * iv.sin(th))
        a2 = h_complex(n, z).abs2()
        if a2.b > worst.b:
            worst = iv.mpf([a2.b, a2.b])
            worst_at = float(2 * math.pi * (i + 0.5) / N)
    M = iv.sqrt(worst)
    log(f"  M_{n}({R}) <= {float(M.b):.6g} "
        f"  (worst arc near theta = {worst_at:.4f})")
    return iv.mpf([M.b, M.b])

def sum8(R=6, mmax=40):
    tot = iv.mpf(0)
    for m in range(4, mmax + 1):
        c = 1
        for t in range(2 * m - 7, 2 * m + 1):
            c *= t
        tot += iv.mpf(c) / iv.mpf(R) ** (2 * m)
    c = 1
    for t in range(2 * mmax - 7, 2 * mmax + 1):
        c *= t
    last = iv.mpf(c) / iv.mpf(R) ** (2 * mmax)
    tot += (last * iv.mpf(2) / iv.mpf(R) ** 2
            / (1 - iv.mpf(2) / iv.mpf(R) ** 2))
    return iv.mpf([tot.b, tot.b])

def part_A(log):

    log("  SUM8 = sum_(m>=4) "
        "(2m)!/((2m-8)! 6^(2m)) "

            f" vs H_8 = 1e12 -> "
            f"{'PASS' if good else 'FAIL'} "
            f" (margin {1e12 / bd:.3g}x)")
    return ok

def phi_abs_bound(n, r, xlo, xhi, K=400):
    p = n - 1 + r
    x = iv.mpf(xlo)
    tot = iv.mpf(0)
    for k in range(1, K + 1):
        tot += iv.mpf(k) ** p * iv.exp(-iv.mpf(k) * x)
    assert K >= 2 * p / xlo
    tail = (iv.mpf(K) ** p * iv.exp(-iv.mpf(K) * x)
            / (1 - iv.exp(-x / 2)))
    return iv.mpf([(tot + tail).b, (tot + tail).b])

def part_B(log):
    edges = [Fr(1), Fr(2), Fr(4), Fr(8), Fr(16), Fr(40)]
    ok = True
    for n in (2, 3, 4):

                        * phi_abs_bound(

            f"<= {worst:.6g} vs H_8 = 1e12 "
            f" -> {'PASS' if worst < 1e12 else 'FAIL'} "
