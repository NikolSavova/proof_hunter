## 2. Lemma E.4a (discretization) — PROVED

**Lemma E.4a.** *For every band constant `gamma* in [0.32, 0.42]`, `m >=
401`, `lam > 0` with `w = m lam > 4`, and `tau in (0, 4/5]`:*

```
sum_{j=1}^m F(j lam) <= (1/lam) Int_0^w F(x) dx + 2 gamma* tau^2 + m eps_env(tau) ,
eps_env(tau) := 1.03 e^{-2 pi/tau} .
```

*Proof.* Split `F = g - 2 gamma* tau^2 h` and bound the two sums
separately, in opposite directions.

*(g-part, upper).* Let `X := 2 pi/tau (>= 2.5 pi)`. For grid points `j lam
<= X`: `g(., tau .)` is strictly decreasing on `(0, X)` (E.3), so `g(j
lam) <= (1/lam) Int_{(j-1)lam}^{j lam} g`; summing over those `j` and
using `g >= 0` to extend the integration range, their total is `<= (1/lam)
Int_0^w g`. For grid points `j lam > X`: `g <= psi <= 1/sinh^2(j lam/2) <=
4.04 e^{-j lam}` (L-env; `j lam > X >= 2 pi`), and

```
sum_{j : j lam > X} e^{-j lam} <= e^{-X} sum_{i>=0} e^{-i lam} = e^{-X}/(1-e^{-lam})
                               <= e^{-X} (1/lam + 1) ,
```

since `1 - e^{-lam} >= lam/(1+lam)`. Now `1/lam = m/w <= m/4` (as `w > 4`)
and `1 <= m/401`, so the beyond-arch total is `<= 4.04 (1/4 + 1/401) m
e^{-X} = 1.0202 m e^{-2 pi/tau} <= m eps_env(tau)`.

*(h-part, lower).* `h` is strictly decreasing with `h(0+) = 1`, so `h(j
lam) >= (1/lam) Int_{j lam}^{(j+1) lam} h` and

```
sum_{j=1}^m h(j lam) >= (1/lam) Int_lam^{(m+1)lam} h >= (1/lam) Int_0^w h - (1/lam) Int_0^lam h
                     >= (1/lam) Int_0^w h - 1 .
```

Multiply the h-inequality by `-2 gamma* tau^2 (< 0)` and add. ∎

*Remark (route item 1, `V'`).* The route proposed certifying a
