## 7. Split analysis: evaluated, NOT adopted

The mandate allowed free band splits. Measured truth profiles are indeed
non-uniform (W7's `r31` spans 1.9114 (w=40+) -> 2.13031 (corner); W3's
spans 1.074 -> 1.3485), but a split cannot raise the WORST-band margin:
the sub-band containing the deep corner (any split of W7) inherits BOTH
the full truth sup (2.13031/6.41126 at `lam = 0.89`) AND the identical row
structure (`lam_max = 0.89` so the same `lam^2/2 = 0.39605` main load,
same `c_A = 0.80`/`cAdag = 0.85`, same C5*, same PROVED tier-1 slot; the
far entry is already `~1e-7`-negligible at `wlo = 40`). So the corner
sub-band's `x_cap` — and with it the global minimum — is unchanged, while
splits only inflate margins on non-binding sub-bands (e.g. a W7a =
(40, 200] would reach ~40% vs truth 2.0046/5.9636 — cosmetic). Same logic
on W1–W6b, where the row cap does not even bind (the 1.35 comfort cap
does). A split would also add statement/referee surface for zero gain in
the objective. Decision: 7 bands, unchanged partition.

discretization gap at 561 is <= 2.2e-3-class (sl4pe F1), i.e. two orders
below every margin below; the m-direction is provably the RIGHT way
(finite-m sits BELOW the limit-sup convention used on W7, and the W1–W6b
targets clear the m = 561 attained sup by >= 32%).
