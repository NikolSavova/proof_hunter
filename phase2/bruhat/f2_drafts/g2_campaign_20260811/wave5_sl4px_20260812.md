## 2. Theorem X.1 and its proof

**Theorem X.1 (SL4'-X, strengthened). PROVED.** *On the box `D` of §1:
`M > 1` (indeed `M >= 1.9238 tau >= 1.53904`), `x(w, tau) > 0`, and for
every fixed `(m, lam)` the map `tau -> x(w, tau)` is strictly increasing
on `[0.8, 1.074]`. In particular SL4'-X holds as recorded, for all bands
`w >= 4` at once.*

The proof substitutes `h = sin(tau lam/2)` and factors `x = P(h) g(h)`:
since `s/(S M) = h^2/(S m h) = h/(m S)`,

```
x = P(h) * g(h),   P(h) := (1/2)(1 - 1/(m h)),   g(h) := log(1 + h^2/S) - h/(m S),
```

with `P' (h) = 1/(2 m h^2) > 0`. Three lemmas control the two factors.

**Lemma X.a (floor for `M`).** *On `D`: `M >= 0.96193 (w tau)/2
>= 1.9238 tau >= 1.53904 > 1`.*

*Proof.* For all `y >= 0`, `sin y >= y - y^3/6 = y (1 - y^2/6)` (the
function `sin y - y + y^3/6` vanishes at `0` and has derivative
`cos y - 1 + y^2/2 >= 0`). On `D`, `y = tau lam/2 <= 0.47793` (NX-1a), so
`1 - y^2/6 >= 1 - 0.47793^2/6 = 0.96193048... >= 0.96193` (NX-1b). Hence
`M = m sin y >= 0.96193 m tau lam/2 = 0.96193 (w tau)/2 >= 0.96193 * 2 tau
= 1.92386 tau >= 1.9238 tau` using `w >= 4` (NX-1c), and at `tau >= 0.8`
this is `>= 1.9238 * 0.8 = 1.53904 > 1` (NX-4). ∎

**Lemma X.b (positivity of the bracket).** *On `D`: `g > 0`.*

*Proof.* Write `X := s/S = h^2/S > 0`, so `g = log(1 + X) - X/M`. Since
`sin y <= y` and `sinh u >= u` for `y, u >= 0`,
`X = (sin(tau lam/2)/sinh(lam/2))^2 <= (tau lam/2)^2/(lam/2)^2 = tau^2`.
The map `phi(X) := X/log(1 + X)` is strictly increasing on `(0, oo)`
(its derivative has the sign of `log(1+X) - X/(1+X) > 0`), so
`X/log(1 + X) <= tau^2/log(1 + tau^2)`. It therefore suffices to prove
`1.9238 tau > tau^2/log(1 + tau^2)` on `[0.8, 1.074]`, i.e. (dividing by
`tau > 0`) `psi(tau) := 1.9238 log(1 + tau^2) - tau > 0`. Indeed
`psi(0.8) = 1.9238 log(1.64) - 0.8 = 0.15169... >= 0.1516 > 0` (NX-2), and
`psi'(tau) = 1.9238 * 2 tau/(1 + tau^2) - 1 >= 1.9238 * 0.9756 - 1
= 0.87685... > 0` on the interval, because `2 tau/(1 + tau^2)` has
derivative `2(1 - tau^2)/(1 + tau^2)^2` — nondecreasing to `tau = 1`, then
nonincreasing — so its minimum on `[0.8, 1.074]` is at an endpoint:
`min(0.97560..., 0.99745...) = 0.97560... >= 0.9756` (NX-3a, NX-3b). Hence
`psi > 0` throughout, so by Lemma X.a
`M >= 1.9238 tau > tau^2/log(1 + tau^2) >= X/log(1 + X)`, which rearranges
to `X/M < log(1 + X)`, i.e. `g > 0`. ∎

**Lemma X.c (the bracket is increasing in `h`).** *On `D`:
`g'(h) = 2h/(S + h^2) - 1/(m S) > 0`.*

*Proof.* `g'(h) > 0` iff `2 m S h > S + h^2` iff `Q(h) := h^2 - 2 m S h +
S < 0`. The discriminant of `Q` is `4 S (m^2 S - 1) > 0`, since
`m sqrt(S) = m sinh(lam/2) >= m lam/2 = w/2 >= 2 > 1`; so `Q < 0` exactly
on `(h_-, h_+)`, `h_± = m S ± sqrt(m^2 S^2 - S)`, with `h_- h_+ = S`. It
remains to place `h` strictly inside `(h_-, h_+)`:

- `h_- < h`: `h_- = S/h_+ <= S/(m S) = 1/m < h`, the last step because
  `M = m h > 1` (Lemma X.a).
- `h < h_+`: `h = sin(tau lam/2) <= tau lam/2 <= (1.074/2) lam
  = 0.537 lam < lam`, while
  `h_+ >= m S = m sinh^2(lam/2) >= m (lam/2)^2 = (w/4) lam >= lam` using
  `sinh u >= u` and `w >= 4`. ∎

*Proof of Theorem X.1.* Fix `(m, lam)` and let `tau` run over
`[0.8, 1.074]`. The substitution `tau -> h = sin(tau lam/2)` is strictly
increasing (`dh/dtau = (lam/2) cos(tau lam/2) > 0` since
`tau lam/2 <= 0.47793 < pi/2`), and `x = P(h) g(h)` as displayed. By Lemma
X.a, `M = m h > 1`, so `P(h) > 0` and `P'(h) = 1/(2 m h^2) > 0`; by Lemma
X.b, `g(h) > 0` — hence `x > 0`; by Lemma X.c, `g'(h) > 0`. Therefore

```
dx/dh = P'(h) g(h) + P(h) g'(h) > 0 ,
```

and `dx/dtau = (dx/dh)(dh/dtau) > 0`: `x` is strictly increasing in `tau`
on `[0.8, 1.074]`. The stated floors `M >= 1.9238 tau >= 1.53904` and
`x > 0` are Lemma X.a and the display above. ∎

## 3. Corollary X.2 — the interval [0.8, 1.074] covers every actual use

**Corollary X.2. PROVED.** *For every `lam in (0, 0.89]`, the upper
integration limit used by the ledger satisfies
`1 < tau_0(lam)/lam = 2 arcsin(sinh(lam/2))/lam <= 1.07372... < 1.074`,
and `lam -> tau_0(lam)/lam` is nondecreasing. Hence
`[0.8, tau_0(lam)/lam]` is a nonempty subinterval of `[0.8, 1.074]` for
every `lam` in the campaign domain, and Theorem X.1 applies to the whole
integration range of every W1 evaluation.*

*Proof.* Put `u := lam/2 in (0, 0.445]` and `r(u) :=
arcsin(sinh u)/u = tau_0(lam)/lam`. First, `sinh(0.445) < 1`, so
`arcsin` is applied inside its domain: `sinh u = u * sum_{k>=0}
u^{2k}/(2k+1)! <= u * sum_{k>=0} (u^2/6)^k = u/(1 - u^2/6)` (since
`(2k+1)! >= 6^k`, an immediate induction), giving `sinh(0.445) <=
0.445/(1 - 0.445^2/6) = 0.46018... <= 0.4602 < 1` (NX-6). Next, with
`D(v) := cosh v / sqrt(1 - sinh^2 v)` (the derivative of
`v -> arcsin(sinh v)`), `D` is increasing on `[0, 0.445]` — numerator
increasing, denominator positive decreasing — so

```
arcsin(sinh u) = ∫_0^u D(v) dv <= u D(u) ,
```

whence `r'(u) = [u D(u) - arcsin(sinh u)]/u^2 >= 0`: `r` is
nondecreasing. Its maximum on `(0, 0.445]` is `r(0.445) =
2 arcsin(sinh(0.445))/0.89 = 1.07372378... <= 1.0739 < 1.074` (NX-5).
And `r(u) > 1` for every `u > 0`, since `D(v) >= cosh v > 1` for `v > 0`
gives `arcsin(sinh u) = ∫_0^u D(v) dv > u`; in particular
`tau_0(lam)/lam > 1 > 0.8`, so the used interval is nonempty. ∎

## 4. Corollary X.3 — the left-endpoint certificate the ledger consumes

**Corollary X.3 (upper-bound property of `X_w6`). PROVED.** *Fix
`(m, lam)` with `w = m lam >= 4`, `lam in (0, 0.89]`, and set
`E(tau) := m x(w, tau)`. For ANY partition `0.8 = tau_0 < tau_1 < ... <
tau_n = tau_0(lam)/lam` (in particular the ledger's uniform `n = 60` and
the referee's `n = 6000`):*

```
∫_{0.8}^{tau0/lam} (tau lam)^2 e^{-E(tau)} lam dtau  <=  Σ_i (tau_{i+1} lam)^2 e^{-E(tau_i)} lam (tau_{i+1} - tau_i) ,
∫_{0.8}^{tau0/lam}              e^{-E(tau)} lam dtau  <=  Σ_i                e^{-E(tau_i)} lam (tau_{i+1} - tau_i) ,
```

*which are exactly the `totn` and `totd` sums of `sl4p_nc1_ledger.py`'s
`X_w6` (weight at the right endpoint, exponential at the left endpoint).
Consequently the W1 `X` row entry of the sl4p ledger is a certified upper
bound, no longer conditional on SL4'-X.*

*Proof.* By Corollary X.2 the integration range lies in `[0.8, 1.074]`,
so Theorem X.1 applies: `E = m x` is (strictly) increasing there, hence
`e^{-E}` is nonincreasing, while `tau -> (tau lam)^2` is increasing. On
each cell `[tau_i, tau_{i+1}]` the integrand is therefore bounded above by
its value with the two monotone factors frozen at their respective worst
endpoints: `(tau lam)^2 e^{-E(tau)} <= (tau_{i+1} lam)^2 e^{-E(tau_i)}`
(first line) and `e^{-E(tau)} <= e^{-E(tau_i)}` (second line). Integrate
over the cell and sum. ∎
