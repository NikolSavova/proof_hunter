## 1. The exact frame and the kernel decomposition

**Setup (exact, from the tilt frame).** For interior `k` with mean-matched
`lam = lam(k)`, `P_delta := P(S_lam = k + delta)` for `delta in {-1, 0, 1}`,
the tilt factors cancel in the ratio and

```
r(k) = P_0^2 / (P_{-1} P_{+1}) ,      s2 (r(k) - 1) = s2 * D / (P_{-1} P_{+1}) ,
D := P_0^2 - P_{-1} P_{+1} ,          P_delta = (1/2pi) int_{-pi}^{pi} phi(t) e^{-i delta t} dt .
```

**Lemma SL4'.1 (kernel identity).** For any decomposition
`P_delta = qhat_delta + rho_delta` (model + remainder, `qhat` from any model
`psi` for `phi` via the same inversion integrals),

```
D = [qhat_0^2 - qhat_- qhat_+]                                  (model term)
  + qhat_0 (2 rho_0 - rho_+ - rho_-)                            (kernel-protected linear term)
  + (qhat_0 - qhat_+) rho_-  +  (qhat_0 - qhat_-) rho_+         (offset-mismatch term)
  + [rho_0^2 - rho_- rho_+]                                     (second order) .
```

*Proof.* Expand `(qhat_0+rho_0)^2 - (qhat_-+rho_-)(qhat_++rho_+)` and
regroup; the linear-in-`rho` part is
`2 qhat_0 rho_0 - qhat_+ rho_- - qhat_- rho_+`, and adding/subtracting
`qhat_0(rho_+ + rho_-)` gives the displayed split. ∎

**Lemma SL4'.2 (kernel weight — the honest transfer).** If `rho_delta` is
the inversion integral of `phi` (or of a model error) restricted to a
symmetric region `T subset [-pi, pi]`, then

```
|2 rho_0 - rho_+ - rho_-| = | (1/2pi) int_T phi(t) * 2(1 - cos t) dt |
                          <= (1/pi) int_{T cap [0,pi]} t^2 |phi(t)| dt ,
```

using `2(1 - cos t) <= t^2` and two-sidedness; while each single
`|rho_delta| <= (1/pi) int_{T cap [0,pi]} |phi(t)| dt`. ∎

This is the whole mechanism of the wave-3 refutation, stated positively:
tail mass enters the NUMERATOR only through the combination
`2 rho_0 - rho_+ - rho_-`, whose weight is `2(1-cos t) <= t^2` — NOT through
the architected `T_u` normalization `A sqrt(s2/2pi) int |phi|` — and it
enters the DENOMINATOR (and the offset-mismatch term) at single-`rho`
weight. Pricing both honestly, in u-units (an entry `E` contributes
`<= E * u` to `s2(r(k)-1) - 1`):

```
numerator entry  =  A * s2 * sqrt(2 pi s2) * (1/pi) int t^2 |phi_err| dt * [normalization inflation] ,
denominator entry =  A * sqrt(2 pi s2) * (1/pi) int |phi_err| dt * [same] ,
```

(the `s2 * sqrt(2 pi s2) = s2/qhat_0`-class factor prices `qhat_0 * (...)`
against `P_- P_+ ~ qhat_0^2`; the inflation is Lemma SL4'.6; the
offset-mismatch and second-order rows are Lemma SL4'.7).
